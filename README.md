# La Programacion
## ¿Que es?
Es el proceso de crear un conjunto de instrucciones ordenadas para decirle a una computadora o dispositivo electrónico cómo realizar una tarea.


**Y ahora para la gente normal:**

Es decirle a un ordenador, paso por paso, qué tiene que hacer para conseguir algo.

## ¿Para que sirve?
- **Desarrollo de software**: Crear aplicaciones para teléfonos, programas de computadora y páginas web.
- **Automatización**: Hacer que procesos repetitivos o industriales se ejecuten de manera automática.
- **Inteligencia artificial y datos**: Procesar información masiva y entrenar sistemas inteligentes.
## Lenguajes de programacion
Los lenguajes de programación son como **idiomas** que usamos para darle órdenes a un ordenador. Cada uno tiene sus propias _reglas y formas de escribir_.

### Por ejemplo:

1. Python → sencillo y muy utilizado para aprender a programar.
1. JavaScript → muy usado para hacer páginas web interactivas.
1. Java → utilizado en aplicaciones, programas y otros sistemas.
1. C++ → usado, entre otras cosas, en videojuegos y programas que necesitan mucha potencia.

## ¿Tienes alguna de estas caracteristicas?

## Importancia de la programación en la actualidad:
La programación es muy importante hoy en día porque está **presente en muchas cosas que usamos todos los días**, aunque no nos demos cuenta. Gracias a la programación funcionan los móviles, las aplicaciones, las páginas web, los videojuegos, los coches modernos[^1]: e incluso algunos electrodomésticos.
